# RESOURCES.md Format

`RESOURCES.md` 是此 topic 的 curated trusted sources set。Explainers 中的 knowledge 应来自这里，而不是 parametric guesses。Wisdom 来自这里列出的 communities。

## Structure

```md
# {Topic} Resources

## Knowledge

- [Book: _The Science and Practice of Strength Training_ — Zatsiorsky & Kraemer](https://example.com)
  Foundational text on programming and adaptation. Use for: anything to do with periodisation, recovery, intensity zones.
- [Article: "How Much Should I Train?" — Greg Nuckols (Stronger By Science)](https://example.com)
  Evidence-based review of volume landmarks. Use for: weekly set targets per muscle group.

## Wisdom (Communities)

- [r/weightroom](https://reddit.com/r/weightroom)
  High-signal subreddit, moderated against bro-science. Use for: programme critique, plateau troubleshooting.
- Local: Tuesday strength class at {gym name}
  Use for: real-time coaching feedback on lifts.
```

## Rules

- **High-trust only.** 偏好 primary sources、recognised experts、peer-reviewed work，以及有 strong moderation 的 communities。如果 resource 是披着 education 外衣的 marketing，leave it out。
- **Annotate every entry.** 三个月后 bare link 没用。添加一行：它覆盖什么，何时 reach for it。
- **Group by Knowledge / Wisdom.** 对应 [SKILL.zh.md](./SKILL.zh.md) 中的 philosophy。一个 resource 只出现在一个 group 也可以。
- **Surface gaps explicitly.** 如果 mission 需要的某个 area 没有 good resource，写一个 `## Gaps` section 列出缺失内容。这会 drive future search。
- **Prune ruthlessly.** 如果某个 resource 后来被证明 wrong、shallow 或 off-mission，就 remove，而不是 bury。五个 sharp sources 好过三十个 mediocre ones。
- **Record community preferences.** 如果用户 opted out of joining communities，在这里 note，避免 future sessions 持续 proposing。
