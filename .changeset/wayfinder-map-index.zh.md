明确 **`wayfinder`** 的 no-duplication contract：map 是 **index**，不是 store。

采用 “index” 作为 map role 的 leading word，修复两个 duplication risks。map 现在开头就说明 decision 只存在于一个地方，也就是它的 Issue，因此 map 只 gist 和 link，永远不重述答案（此前这条规则只隐含在 map-body template 的 HTML comment 中）。同时，把 fog 升级为 Issue 时，会从 Fog 中清除已升级 patch，使 suspected question 不会同时留在两个地方。
